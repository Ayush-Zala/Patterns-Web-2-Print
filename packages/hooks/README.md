# @patterns/hooks

Shared React hooks for the Patterns monorepo frontend applications.

## Purpose

Centralize frontend business logic, API fetching, and generic React hooks (e.g. `usePagination`, `useWorkspace`) to be shared between the CMS, Editor, and Website.

## Current State

This is currently a placeholder for future implementation.

## Dependency Rules

- **Can Import:** `@patterns/api-client`, `@patterns/utils`, `@patterns/types`
- **Can be Imported by:** Frontend applications (`cms`, `website`, `editor`).
