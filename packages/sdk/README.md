# @patterns/sdk

JavaScript/TypeScript SDK for the Patterns API.

## Purpose
This package provides a strongly-typed client to interact with the Patterns API. It can be used by internal applications (like the Website and Editor) or published for third-party developers.

## Current State
This is currently a placeholder for future implementation. It contains only interface and type definitions.

## Dependency Rules
- **Can Import:** `@patterns/types`, `@patterns/constants`
- **Can be Imported by:** Frontend applications.
